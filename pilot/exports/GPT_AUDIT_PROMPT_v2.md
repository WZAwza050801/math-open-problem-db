# 第三方质检提示词 v2（针对 Crossref 权威语料版）

> 用法：把下面整段贴给网页版 GPT，并把 `REVIEW_v3.md` 全文（或其中若干篇）粘在最后。
> 与 v1 的差别：本次语料每一篇都有 Crossref DOI 背书，因此**刊名/年份可以直接查证而不是推测**；
> 质检重点从"是不是真论文"转移到"提取本身是否忠实"。

---

你是一位严格的数学文献质检员。下面是一份「AI 从数学顶刊论文中自动提取开放问题」的产出报告，请你做第三方质检。**不需要客气，你的价值在于找出错误。**

## 背景与口径

- 语料来自五个期刊：Annals of Mathematics / Acta Mathematica / Inventiones Mathematicae / Journal of the American Mathematical Society / Publications Mathématiques de l'IHÉS，发表年份 2000–2025。
- **每篇论文都由 Crossref 提供权威的刊名、DOI、出版年**，并已与 arXiv 预印本按 DOI 或标题精确连接。所以"这篇论文是否真的属于该刊"是可查证的，**请直接核验，不要因为标题陌生就判为伪造**。
- 如果某篇的 DOI 与实际内容不符（例如标着 Annals of Mathematics 但 DOI 前缀是 `10.1007/s00222`），这是**严重错误**，请单列。

## 标签体系（六分类，必须按此判）

| 标签 | 含义 |
|------|------|
| `real_open` | 论文自己提出的真开放问题（核心产出，价值最高） |
| `background_open` | 论文引用的著名背景开放问题（非本文目标） |
| `method_obstruction` | 论文显示某方法/估计失效或需要额外假设，但**未正式提问** |
| `future_application` | 应用展望、品味评论（**不是数学命题**） |
| `solved_in_paper` | 论文自己已经证明/证伪 |
| `uncertain` | 上下文不足 |

`paper_time_status` 记录**论文写作当时**该问题是否未解决；`current_status` 必须一律是 `unknown`（今天的状态由另一个专门的文献追踪环节填写，本报告不负责）。

## 请你逐条检查的五类问题

**A. 引文是否伪造（最高优先级）**
每条卡片的 `original_quote` 声称是从原文逐字摘录。请抽查你认为最可疑的 5–8 条，对照论文原文（你有联网检索能力，可以用 DOI 或标题去找原文；找不到原文时请明确说明"无法核验"，不要猜）。
判定：`VERBATIM` / `PARAPHRASE`（改写而非逐字）/ `NOT_FOUND`（疑似伪造）。

**B. 数学条件是否被改动**
这是最危险的错误类型。请重点检查含参数范围、不等式、渐近阶的卡片：
- 原文说 `0<ℓ<1`，卡片是否写成 `ℓ>0`？
- 原文说"某类流形"，卡片是否擅自加上"紧致"或"完备"？
- 原文的指数/系数是否被改动？
判定：`FAITHFUL` / `WEAKENED`（条件被放宽）/ `STRENGTHENED`（条件被加强）/ `DISTORTED`（结论本身改了）。

**C. 标签是否正确**
特别是：
- 有没有把**论文已解决**的东西标成 `real_open`？
- 有没有把**非命题**（品味评论、应用展望）标成 `real_open` 或 `method_obstruction`？（这是"任务化"，是已知的高发错误）
- 有没有把**著名背景问题**（如 abc 猜想、Riemann 猜想）标成本文的 `real_open`？

**D. 自包含性**
`self_contained` 字段要求"不依赖论文上下文即可读懂"。请检查是否存在：
- 引用了未定义的记号（"如上所述""该算子"等）；
- 省略了关键定义或假设；
- 需要读了原论文才知道在说什么。
判定：`SELF_CONTAINED` / `NEEDS_CONTEXT`。

**E. 重复计数**
同一篇论文内，是否有两条卡片其实是同一个问题（一条一般情形、一条特殊情形或实现）？跨论文是否出现同一个著名问题被反复当作不同条目？（`background_open` 类尤其容易重复。）

## 输出格式

先给总表：

| # | 卡片ID | 论文 | 检查项 | 判定 | 一句话理由 |
|---|--------|------|--------|------|-----------|

然后给结论：

1. **总体可信度评分（0–10）**，并说明扣分点。
2. **必须修的硬错误清单**（区分 FAIL / SUSPECT）。
3. **`real_open` 类卡片的可用率**：在你抽查的 `real_open` 卡片中，有几条真的可以拿去做推荐系统的题目？
4. **你认为这套提取流水线下一步最该改的三件事**。
5. 如果你发现任何"整体性偏差"（例如某一类问题被系统性漏掉、某个期刊的提取明显更差），请单独指出——这比单条错误更有价值。

## 重要提醒

- 拿不准就写"无法核验"，**不要编造原文内容**。
- 不要因为卡片写得漂亮就给高分，也不要因为文体问题扣分，只关注**事实与数学内容**。
- 如果发现某条卡片的引文在原文里根本不存在，这是**最严重的问题**，请明确列出卡片 ID。
